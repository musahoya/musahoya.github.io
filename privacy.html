모두문서 개인정보처리방침

장진호세무회계사무소(이하 "사무소")는 Android 앱 「모두문서」(이하 "앱")를 제공하면서 「개인정보 보호법」 등 관련 법령을 지키고, 이용자의 개인정보와 문서를 보호하기 위해 다음과 같이 개인정보처리방침을 둡니다.

1. 앱의 기본 원칙

  • 앱은 회원가입·로그인이 없고, 사무소가 운영하는 서버가 없습니다.
  • 문서 열기·편집·저장·서식 작성은 모두 휴대폰 안에서 처리되며, 사무소는 이용자의 문서나 입력값을 받지 않습니다.
  • 앱에는 광고·분석·추적 SDK가 없습니다.
  • 인터넷은 이용자가 AI 기능(AI 편집·새 문서 만들기·서식 칸 채우기)을 직접 실행할 때만 사용합니다.

2. 처리하는 정보와 목적

구분 처리 항목 처리 장소 목적
문서 편집 이용자가 연 HWP·HWPX·DOC·DOCX·XLS·XLSX·TXT·MD·JSON·PY 파일 내용 휴대폰 안 문서 보기·편집·저장
세무서식 작성 납세자 성명, 주민·사업자등록번호, 주소, 연락처, 세목·금액·기한 등 입력값 휴대폰 안 국세 서식(HWP/PDF) 작성
AI 기능(선택) AI 편집: 이용자가 선택한 문장, 문서 전체 글자, 또는 텍스트 파일 전체 / 새 문서 만들기·서식 칸 채우기: 이용자가 적은 요청 문장(주민등록번호로 보이는 숫자는 가려서 전송) 이용자가 고른 AI 서비스(아래 4항) 문장 교정·재작성, 새 문서 초안 작성, 서식 입력칸 채우기
AI API 키(선택) 이용자가 입력한 OpenAI/Anthropic API 키 휴대폰 안(암호화 저장) AI 서비스 호출 인증
앱 설정 고른 AI 모델, 세무서식의 일반 항목(세무서, 날짜 등) 휴대폰 안 다음 사용 때 편의
  • 세무서식의 납세자 성명·주민·사업자등록번호·주소·연락처는 서식을 만든 뒤 휴대폰에 저장하지 않습니다.
  • 사무소는 위 정보를 수집하거나 사무소로 전송하지 않습니다.

3. 보유 기간과 파기

  • 편집한 문서는 이용자가 '저장'을 누른 경우에만 휴대폰의 문서/모두문서 폴더에 저장되며, 이용자가 직접 지울 때까지 남습니다.
  • 다른 앱에서 열거나 공유하기 위해 만든 임시 파일은 앱 전용 임시 폴더에 두며, 새 파일을 열면 이전 임시 파일을 지웁니다.
  • AI API 키는 앱의 'API 키 설정'에서 '삭제'를 누르면 즉시 지워집니다.
  • 앱을 삭제하면 앱 안에 저장된 설정·API 키·임시 파일이 모두 지워집니다(문서/모두문서 폴더에 저장한 문서는 이용자 파일이므로 남습니다).

4. AI 기능 사용 시 제3자 제공 및 국외 이전

AI 기능은 선택 기능입니다. 이용자가 '수정안 만들기', '문서 만들기', 'AI로 칸 채우기' 버튼을 누를 때에만, 이용자의 휴대폰에서 이용자가 고른 AI 서비스로 직접 전송됩니다(사무소 서버를 거치지 않음). 앱은 처음 AI를 실행할 때 이 내용을 알리고 동의를 받습니다.

항목 내용
이전받는 자 OpenAI, L.L.C. 또는 Anthropic, PBC (이용자가 선택한 곳 하나)
이전 국가 미국
이전 시기·방법 AI 실행 시 암호화된 인터넷 통신(HTTPS)으로 전송
이전 항목 선택한 문장, 문서 전체 글자(표 안 글자 포함) 또는 텍스트 파일 전체, 편집 지시문, 새 문서 만들기·서식 칸 채우기에 적은 요청 문장(주민등록번호로 보이는 숫자는 가려서 전송), 이용자 본인의 API 키
이용 목적 문장 교정·재작성, 새 문서 초안 작성, 서식 입력칸 채우기 결과 생성
보유·이용 기간 각 AI 서비스의 개인정보처리방침과 API 데이터 정책에 따름. OpenAI 호출에는 대화 저장을 하지 않도록 요청(store: false)합니다
거부 방법과 불이익 AI 기능을 사용하지 않으면 전송되지 않으며, 그 밖의 기능은 모두 그대로 쓸 수 있습니다

주의: 고객의 주민등록번호 등 민감한 정보가 들어 있는 문서는 AI 편집에 보내기 전에 해당 내용을 지우거나 가리는 것을 권장합니다. 새 문서 만들기·서식 칸 채우기에 적은 요청 문장은 앱이 주민등록번호 형태의 숫자를 자동으로 가린 뒤 보냅니다.

5. 개인정보 처리 위탁

사무소는 개인정보 처리 업무를 외부에 위탁하지 않습니다.

6. 안전성 확보 조치

  • AI API 키는 Android Keystore의 AES-256-GCM 키로 암호화해 앱 전용 저장소에 보관합니다.
  • 앱 데이터는 Android 자동 백업에서 제외됩니다(allowBackup=false).
  • AI 서비스와의 통신은 HTTPS로만 합니다.
  • 세무서식의 납세자 식별 정보는 휴대폰에 남기지 않습니다.

7. 이용자의 권리

이용자는 앱 안의 데이터를 언제든지 직접 확인·삭제할 수 있습니다(저장한 문서 삭제, API 키 삭제, 앱 삭제). 사무소는 이용자의 개인정보를 보관하지 않으므로 사무소에 대한 열람·정정·삭제 요청 대상 정보가 없으나, 문의는 아래 연락처로 받습니다.
